# 每日数学 · Daily Math

每天学习一条数学定理或公式。复古电脑风格，支持手机阅读、离线学习，以及自行编辑课本、推导、例题和练习题。

## 文件说明

| 文件 | 用途 |
| --- | --- |
| `index.html` | 学习网站首页，内含当前学习内容、字体、脚本和七个数学动画视频 |
| `editor.html` | 可视化编辑器，也是包含 HTML、CSS 和 JavaScript 的完整编辑器源文件 |
| `licenses/` | 随项目分发的字体授权说明 |

这是一份可直接运行的单文件发布版本。无需 npm、数据库或构建工具。README 是使用说明，实际程序保存在 HTML 文件中。

## 使用

下载 `index.html` 后，用支持 JavaScript 的浏览器打开即可学习。在线部署后，可通过手机浏览器访问网站。离线使用需要先下载 HTML 文件；iPhone 的文件预览可能无法执行脚本，需要使用支持本地 HTML 和 JavaScript 的浏览器或查看器。

目前包含课本学习、预备知识、分步推导、例题、练习、百分制模拟考试、公式大全、错题本、收藏、打卡、风格切换及视频学习。

学习进度、错题、收藏、打卡和编辑草稿主要保存在当前浏览器中，不会自动同步到 GitHub、其他设备或其他域名。清理浏览器前请使用页面提供的备份功能。

## 添加内容与修改外观

1. 下载 `editor.html`，在浏览器中打开。
2. 在学习内容中添加或选择课本、定理，填写公式、预备知识、推导步骤和例题。
3. 在题库中添加选择、填空或简答题，并填写答案与解析。
4. 设置默认题量；0 表示全部。学习者也可以在开始练习或考试前自行设置题量。
5. 在外观设置中修改配色、背景、排版，或选择默认风格。高级模式支持 CSS 和完整 HTML 源码编辑。
6. 点击“导出学习版 HTML”，将导出的文件命名为 `index.html`，替换仓库根目录中的同名文件。
7. 如果也要分享修改后的编辑器，使用“导出编辑器副本”，将导出的文件命名为 `editor.html` 并一并更新。
8. 使用“保存工程”保留自己的 JSON 工程备份，下次通过“打开工程”继续编辑。

编辑器保存草稿或导出文件后，网站不会立即更新。必须把新版 `index.html` 提交到 GitHub，才会触发 Cloudflare 部署。工程 JSON 不会自动加载到网站中。

新增文字按输入语言显示，不会自动翻译；填空题按预设答案匹配；简答题提供参考答案，由学习者自评。修改完整源码后，请自行检查功能。

在线访问 `/editor.html` 时，每位使用者编辑的是自己浏览器里的副本；保存不会覆盖公共网站。编辑器没有后台写入权限。

## Cloudflare Pages 部署

将本目录里的文件和 `licenses` 文件夹放在 GitHub 仓库根目录，确保首页文件为 `index.html`。

在 Cloudflare 中创建 Pages 项目，连接该 GitHub 仓库，设置如下：

| 项目 | 值 |
| --- | --- |
| 生产分支 | `main` |
| 框架预设 | `None` |
| 构建命令 | `exit 0` |
| 构建输出目录 | `.` |
| 根目录 | 默认，不填写 |
| 环境变量 | 无需添加 |

首次部署成功后，在 Pages 项目的 Custom domains 中绑定自己的域名。之后提交到 `main` 的更新将触发自动部署，在 Deployments 页面确认成功。

## 欢迎贡献

可以通过 Issues 提出公式纠错、功能建议和内容补充。要提交修改，请先 Fork 本仓库，在自己的副本中修改，再发起 Pull Request，由维护者审核后合并。只有合并到生产分支后，修改才会发布到本网站。

添加数学内容时，请写清适用条件、符号含义、必要的预备知识、完整推导、例题和答案解析；注明参考书目与章节，并用自己的语言编写。修改页面后，请检查手机排版、公式显示、练习评分、导出和视频播放。
